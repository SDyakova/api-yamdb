# API YaMDb

API для сервиса YaMDb — платформы для сбора отзывов пользователей на произведения различных категорий и жанров.

Произведения делятся на категории (фильмы, книги, музыка) и жанры (драма, комедия, рок и т.д.). Пользователи могут оставлять отзывы с оценкой от 1 до 10 и комментировать чужие отзывы.

## Роли пользователей

- **Аноним** — только просмотр
- **Пользователь** — отзывы, комментарии, оценки
- **Модератор** — редактирование любых отзывов и комментариев
- **Администратор** — полный доступ, создание/удаление произведений, категорий, жанров

## Как запустить

Клонировать репозиторий и перейти в папку:
git clone <url>
cd api_yamdb

Создать виртуальное окружение и активировать:
python -m venv venv
source venv/Scripts/activate

Установить зависимости:
pip install -r requirements.txt

Выполнить миграции и запустить:
cd api_yamdb
python manage.py migrate
python manage.py runserver

Документация: http://127.0.0.1:8000/redoc/

## Загрузка тестовых данных

python manage.py load_csv_data

## Примеры запросов

### Регистрация

POST /api/v1/auth/signup/
{"email": "user@example.com", "username": "user"}

### Получение токена

POST /api/v1/auth/token/
{"username": "user", "confirmation*code": "код*из_письма"}

Ответ: {"token": "..."}

### Список произведений

GET /api/v1/titles/

Ответ: [{"id": 1, "name": "Название", "year": 2020, "rating": 8, "category": {...}, "genre": [...]}]

### Добавить отзыв

POST /api/v1/titles/1/reviews/
Authorization: Bearer <токен>
{"text": "Отличное произведение!", "score": 10}
